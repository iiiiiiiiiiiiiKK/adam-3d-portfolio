## 1. Why you need this

Late at night you open the stream and see Neuro-sama playing Minecraft while bantering with chat: fast reactions, plenty of jokes, and redstone machines being built on the side. But when the stream ends, this "digital life" is gone — she isn't open source, so you can't invite her home.

Worse, the mainstream AI companion tools (Character.ai, JanitorAI, SillyTavern) can only chat — Character.ai has hundreds of millions of monthly users and still can't play games with you. Most open-source AI VTubers get stuck on local deployment, GPU requirements and cross-platform compatibility, so ordinary players never get them running.

As of March 2026, Project AIRI on GitHub — 47,766 stars — has an answer: an AI digital companion that is actually yours, runs in the browser and on desktop, plays games with you, and talks to you in real time by voice.

## 2. In one sentence: what is this project

**Project AIRI** is a self-hosted, user-owned AI companion platform inspired by Neuro-sama, positioned as "a soul container for cyber life." Core features: real-time voice chat, playable Minecraft and Factorio, and cross-platform support for Web/macOS/Windows/Linux/iOS/Android. The latest release v0.10.2 is out, with 23+ LLM providers and 5 TTS engines.

## 3. A deep dive into the core features

### 1. Real-time voice chat: an end-to-end audio pipeline

AIRI ships a complete "ears + mouth" chain: microphone capture in the browser + on-device speech recognition (VAD for speech detection) + LLM inference + multi-provider TTS synthesis. Its in-house `unspeech` proxy normalizes ElevenLabs, Azure, OpenAI-compatible endpoints, Alibaba Cloud and Local Kokoro into the standard OpenAI format, so swapping TTS needs no changes to business code.

### 2. AI game companion: more than chatting

This is AIRI's killer feature — the AI actually plays the game. Minecraft is driven server-side through the Mineflayer protocol, Factorio is orchestrated through the RCON API via the `autorio` automation library, and Kerbal Space Program is on the roadmap. The Electron desktop build uses NVIDIA CUDA and Apple Metal acceleration by default, while the browser build falls back to WebGPU/WebAssembly.

### 3. A cross-platform Stage: the browser is her body too

AIRI folds Live2D and VRM character models into the Stage: auto blinking, gaze tracking and idle eye drift are all built in, and the same code runs on Web, Electron and Capacitor (PWA/iOS/Android). Developers extend it with Vue 3 + TypeScript — zero platform branching.

### 4. A fully local data layer: DuckDB-WASM + pgvector

The memory system uses `@proj-airi/duckdb-wasm` to run a DuckDB data warehouse inside the browser; the planned Memory Alaya will connect pgvector for long-term memory and RAG. That means even with the network cable unplugged, the AI can recall what you talked about.

## 4. Technical highlights and performance

- **Native to the web stack**: WebGPU, WebAudio, Web Workers, WebAssembly and WebSocket have been wired in since day 1, with CUDA/Metal as the desktop fallback — dodging the "the web is slow" stereotype.
- **23+ LLM providers**: OpenAI, Claude, Gemini, DeepSeek, Qwen, Ollama and vLLM all work out of the box, behind a unified direct-connect layer `xsai` that is only 6KB.
- **i18n coverage**: Simplified Chinese, English, Japanese, Russian, Vietnamese, French and Korean — 7 languages, translated collaboratively on Crowdin.
- **An ecosystem matrix**: 12+ sub-projects have spun up, including `xsai-transformers`, `mcp-launcher` and `@proj-airi/drizzle-duckdb-wasm`.

## 7. How to get started quickly

Fastest desktop path (Windows):

```powershell
winget install MoeruAI.AIRI
```

macOS users:

```bash
brew install --cask airi
```

Linux/NixOS users:

```bash
nix run github:moeru-ai/airi
```

Developers starting from source:

```bash
pnpm i
pnpm dev            # browser Stage
pnpm dev:tamagotchi # desktop Electron
pnpm dev:pocket:ios # iOS mobile
```

Configure an LLM key (any one provider) and the character comes alive. The official Discord has 13,000+ members answering questions.
