# Too many Agent Skills to choose from? This GitHub project merges 10+ platform leaderboards into one table

## 1. Opening: why you need this tool

AI coding tools extend their capabilities through Skills. This year Skills repos have sprouted everywhere: skills.sh, ClawHub, Tencent SkillHub, GitHub, the X community. Each platform only measures its own ecosystem. To pick a Skill that's actually good, a developer has to bounce between 5+ sites, compare numbers, and still worry: "the same name shows ten-times different numbers on two platforms — who do I believe?"

The bigger problem is that popular isn't the same as useful. Want "the fastest risers of the last 7 days"? No platform gives you that. Want "the most downloaded among officially verified publishers"? You have to aggregate across platforms yourself. Want to know "is anyone really talking about this Skill, or does the name just collide with something else"? The default leaderboards can't answer that at all.

That's exactly what LinklyAI/best-skills does: it merges install counts, growth rates and social buzz from 10+ communities into 9 comparable daily leaderboards, with open CSV data you can take and use. GitHub 605 stars, CC BY 4.0, free for commercial use.

## 2. What it is: the problem it solves

LinklyAI/best-skills is a **cross-platform leaderboard for Agent Skills**, refreshed daily across 9 leaderboards and tracking 10,000+ Skills, covering install counts, weekly growth, social buzz, maintenance activity, official verification, and rising newcomers.

Core features:
- **Cross-ecosystem aggregation**: skills.sh (Claude/Vercel CLI installs), ClawHub (OpenClaw downloads), Tencent SkillHub (domestic installs), GitHub repo stars, Twitter/X, Hacker News and Bluesky all counted together.
- **Raw data preserved**: every CSV ships with per-platform raw numbers, so anyone can re-check and re-rank. No apples-plus-oranges blending.
- **AI judge validation**: TypeSafe's jev decision model decides whether a social post is really about this Skill and whether a listing is a Skill that's actually maintained. Every judgment's probability is public, and placeholder, deprecated or harmful entries get filtered out.
- **Native support for AI agents**: an `llms.txt` lets Claude Code, Codex, Cursor and OpenClaw read it in one command; it can also be installed as a persistent skill via `npx skills add`.

The project runs 9 leaderboards tracking 10,000+ Skills, with READMEs in English, Chinese, Japanese, Korean, Spanish, German and Russian.

## 3. Core features in depth

![](/assets/blog-images/agent-skills-github-10-dful96/img02.webp)

### 1. Nine daily leaderboards: every angle of the selection problem

The project offers 9 complementary leaderboards, each answering one question:

- **best-100 (Worth-Installing Score)**: a ranking from "popularity + momentum + social buzz + maintenance + trust", for the "which Skills should I install" starting question. #1 is agent-browser (WIS 80.7), #2 is frontend-design (78.2).
- **top-installs**: install counts from every ecosystem shown side by side — plainly telling you "find-skills has 3.59M installs on skills.sh", "dev-expert has 1.62M on SkillHub" — without forcing a sum.
- **trending-7d**: the 7-day growth chart for catching new waves. ai-video-generation is up 12.8% for the week.
- **social-buzz**: a four-source buzz chart across X, HN, Bluesky and GitHub, automatically excluding Skills whose "names are too generic and ownership unclear".
- **most-active**: who ships most often among popular Skills; chinese-official-writing with 132 versions takes first.
- **official-100**: popular Skills from platform-verified publishers, with unofficial entries removed.
- **official-vendors**: verified vendors ranked by total installs; microsoft has 582 Skills and 7.09M installs.
- **top-repos**: the underlying GitHub repo star chart; obra/superpowers leads at 292k stars.
- **rising-stars**: newcomers from the past 30 days, ranked by popularity, to help you spot tomorrow's winners.

### 2. Side-by-side display across platforms instead of blending

The core methodology is **"don't add apples and oranges."** Cross-platform numbers are always shown side by side, and ranking uses a "within-platform percentile composite." Every CSV row gives both the composite WIS and each platform's raw number, and a "Cov" column marks how many platforms back the score (A = all three, C = only one), so you don't put trust in a single source by mistake.

### 3. AI judge jev: keeping the buzz chart free of name-collision noise

The biggest trap in social buzz is misattribution by name. The name agent-browser appears 80+ times on X — but how many are actually about this Skill from vercel-labs? The project hands every candidate post to the jev model to score: is this post about this Skill, is this listing actually maintained, is the category right. Every probability is public, and you can dig through the raw judgments in `data/latest/rankings/judgments.csv`. That separates real discussion from name collisions cleanly.

### 4. Open CSV plus llms.txt: consumable by humans and AI alike

All data lives as CSV under `data/YYYY-MM-DD/`, archived per day, while `data/latest/` is always the newest day. For humans, `linkly.ai/skills` offers interactive visualizations. For AI agents, send `Read https://linkly.ai/skills/llms.txt` and Claude Code, Cursor and the like will follow the llms.txt instructions to pick files, read fields and compare on their own. Want the leaderboard as persistent agent knowledge? One line: `npx skills add https://github.com/LinklyAI/best-skills --skill best-skills`.

## 4. Technical highlights and performance data

![](/assets/blog-images/agent-skills-github-10-dful96/img03.webp)

- **Data scale**: 10,000+ Skills tracked, 9 leaderboards, 9 core metric dimensions.
- **Data sources**: 4 install sources (skills.sh, ClawHub, Tencent SkillHub, GitHub API) plus 4 social sources (X, HN, Bluesky, GitHub search), collected incrementally every day.
- **AI judge**: the jev-1.13 decision model scores every candidate probabilistically, filtering placeholder, deprecated and harmful listings.
- **Open license**: CC BY 4.0, commercial use allowed; the only requirement is keeping the attribution "Data from Best Skills by @BlueeonY — CC BY 4.0".
- **Architecture**: a two-layer "raw data + derived leaderboards" directory, archived daily under `data/YYYY-MM-DD/` with `data/latest/` symlinked to the newest, so everything is traceable and reproducible. Single CSV format, no database lock-in, git diffs stay readable.
- **Ecosystem compatibility**: the llms.txt standard lets any AI agent consume it at zero cost, and `npx skills add` installs it as a persistent agent skill in one command.

## 7. Getting started

**Up and running in 3 minutes**:
1. Open the visualization page: `https://linkly.ai/skills` and switch between the 9 tabs.
2. Download raw data: clone the repo, go to `data/latest/`, and grab the CSV you need (e.g. `best-100.csv`).
3. Let an AI agent read it: `Read https://linkly.ai/skills/llms.txt`, paste the output into Claude Code / Codex / Cursor, and just ask "which three frontend Skills grew fastest in the last 7 days?"

**Advanced usage**:
- Install as a persistent agent skill: `npx skills add https://github.com/LinklyAI/best-skills --skill best-skills`, and the agent knows the latest leaderboards every day.
- Secondary analysis: combine `data/index/first-seen.csv` with the daily leaderboard to compute newcomer retention curves; use the per-platform raw numbers in `data/YYYY-MM-DD/raw/` to compute composite metrics of your own design.
- Commercial citation: add one line to your product or article — "Data from Best Skills by @BlueeonY — CC BY 4.0" — and you're done. No extra permission needed.
