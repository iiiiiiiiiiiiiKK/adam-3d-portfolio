## 2. Project intro: what it is in one sentence

## 3. Core features in depth

### 1. ⚖️ Arbitrage strategy

The logic is blunt: in the same Polymarket market, if `YES price + NO price < $1.00`, the bot immediately buys both sides and pockets the spread at settlement. v3.1 raised the minimum profit threshold from 0.5% to 1%, specifically to cover Gas fees on Polygon and avoid the embarrassment of "earning the Gas money and paying it right back". Risk on this strategy is very low, making it the stable base of the bot's returns.

### 2. 📉 Dip arbitrage (DipArb)

Built for extreme moves in 15-minute crypto markets (BTC, ETH): when price drops more than 15% within 3 seconds, the bot immediately buys the crashed side (Leg 1), then hedges by buying the other side (Leg 2). Whichever way the market settles, the two-leg combination locks in profit. The new "minimum $1.50 position" constraint in v3.1 ensures every position can be closed normally, eliminating the risk of getting stuck with no exit.

### 3. 🐋 Smart money copy trading

The bot automatically scans Polymarket leaderboards for high-win-rate traders and copies their moves. v3.1 raised the filter bar significantly:

- Win rate ≥ 60% (was 50%)
- Total profit ≥ $500 (was $100)
- Profit/loss ratio ≥ 1.5x
- Consistency score ≥ 70%
- Single-trade profit share ≤ 30% (filters out whales who got lucky on one all-in bet)

This filter changes the copy targets from "people who have made money" to "people who keep making money".

### 4. ⚡ Direct trading tools

A "superpower toolbox" for manual traders, including FOK (Fill or Kill), Sniper (fast sweeps slightly above market price) and other shortcuts. v3.1 added a 15% stop loss, 25% take profit and a 7-day maximum holding period, closing the most common manual trading gap: forgetting to sell.

## 4. Technical highlights and performance data

Every core upgrade in v3.1 revolves around "capital safety", across three dimensions:

1. 4-layer risk control
   - Layer 1: intraday loss of 5% pauses trading for 60 minutes
   - Layer 2: 15% loss over 30 days pauses until the end of the month
   - Layer 3: 25% drawdown pauses for 7 days
   - Layer 4: 40% cumulative loss shuts the bot down permanently

2. Dynamic position sizing
   - Base position cut from 3% to 2%
   - Each additional loss multiplies size by 0.8 (after 3 losses a single trade drops to $3.20)
   - Each win adds 10%, capped at 5% (after 5 wins a single trade is $7)

3. Engineering details
   - Polygon Gas fees accounted for separately
   - Browser dashboard shows PnL and risk status in real time
   - One-click switch between Dry Run / Live mode
   - Emergency Stop + Panic Sell as a double safety net

On the ecosystem side, the project works with both MetaMask and Polymarket proxy wallets. Deployment only needs Node.js 18+, with full support for Windows / macOS / Linux.

## 7. How to get started fast

### Minimal deployment steps

1. Clone the repository

   `git clone https://github.com/MrFadiAi/Polymarket-bot.git && cd Polymarket-bot`

2. Install dependencies and build the dashboard

   `npm install && cd dashboard && npm install && npm run build && cd ..`

3. Copy `.env.example` to `.env`, fill in the `POLYMARKET_PRIVATE_KEY` exported from MetaMask, and set `CAPITAL_USD=50`, `DRY_RUN=true`

4. Start the bot

   `npx tsx bot-with-dashboard.ts`

5. Open `http://localhost:3001` in a browser and the dashboard is there

### Advanced advice

- Run Dry Run for 24-48 hours first and watch how often the strategies trigger
- On days 3-9 switch to Live but still validate with a small $50 balance
- From day 10, scale gradually to $250+ based on the PnL curve
- Always keep 1-5 dollars of MATIC for Gas fees
- Never commit your wallet private key to GitHub or share it in screenshots
